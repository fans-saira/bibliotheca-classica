# Projetos de livros

Cada livro tem uma pasta própria, com fontes, dados, imagens, revisões,
instruções de compilação e resultados específicos da edição.

- [Persas, de Ésquilo](persas/README.md): edição em ConTeXt com vocabulário
  e gramática na margem; [PDF atual](persas/output/pdf/persas-integral.pdf).

Novos livros devem seguir a estrutura `livros/<identificador-do-livro>/`,
com seu próprio README. A implementação web fica separada, em [`../html/`](../html/).
